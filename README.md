# AF7 Sample Books Flipbook

Interactive 3D flipbook of the seven AF7 Apparel Fastener sample books (30 pages, 36 x 29.7 cm).

Books: Metal Zippers, Aluminium Zippers, Nylon Coil Zippers, Moulded Plastic Zippers, Tag Strings, Metal Tipping, TPU Tipping.

## View

Open `index.html` in a browser, or enable GitHub Pages (Settings, Pages, deploy from branch `main`, root folder).

Turn pages by clicking a page, using the arrow buttons or arrow keys, or swiping on mobile. Switch books with the tabs at the top.

## Files

- `index.html`: the flipbook (HTML, CSS and JavaScript in one file)
- `p/`: page images, `pg-01.jpg` to `pg-30.jpg`
- `logo.png`, `montserrat.woff2`: brand assets
